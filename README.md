# EEG-Guided Personalized Targeted Memory Reactivation in aMCI

## 1. Project Overview
This project is a literature review exploring the potential of EEG-guided personalized Targeted Memory Reactivation (TMR) during sleep to improve memory consolidation in individuals with amnestic Mild Cognitive Impairment (aMCI).

## 2. Data and Sources
The project uses published scientific literature, including peer-reviewed research articles, systematic reviews, and meta-analyses related to:
- EEG and Event-Related Potentials (ERP).
- Sleep slow oscillations and memory consolidation.
- Auditory stimulation and Targeted Memory Reactivation.
- Mild Cognitive Impairment (MCI) and Alzheimer's disease.

No original patient data or EEG recordings are currently collected or analyzed.

## 3. Methodology
The literature review involves:
1. Searching for relevant scientific publications.
2. Organizing references using Zotero.
3. Screening studies based on their relevance to the research question.
4. Critically evaluating study methods, findings, and limitations.
5. Comparing findings and identifying research gaps.

No computational EEG analysis is currently performed.

## 4. Software and Requirements
- Zotero: Reference management and organization.
- Microsoft OneNote: Research notes and documentation.
- GitHub: Research project documentation and version control.
- Web browser: Accessing scientific databases and publications.

No additional software installation or code execution is required at this stage.

## 5. Project Status
Currently, the project is in the literature review stage. The repository will be updated as the research progresses.
